# Árbol de derivaciones
Se debe entrar a la carpeta del proyecto, teniendo la extension de ANTLR y al presionar f5 se genera el árbol de derivaciones para el ejemplo que haya en el archivo input.txt, el archivo puede ser modificado, o copiar y pegar el contenido en los ejemplos del repositorio, posteriormente Ctrl+S para guardarlos y f5 para compilar y generar
